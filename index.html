1. Introducción

Bienvenido a PRIVATE CHAT, una aplicación de mensajería privada desarrollada por MaxStudio.

Esta Política de Privacidad explica qué información puede tratar la aplicación, cómo se utiliza y qué derechos tienen los usuarios.

Nuestro objetivo es ofrecer una experiencia de comunicación privada, transparente y segura.

2. Registro e inicio de sesión

PRIVATE CHAT permite acceder mediante:

  • Cuenta de Google.
  • Correo electrónico.

Para gestionar la autenticación y las cuentas, la aplicación puede tratar información como:

  • Dirección de correo electrónico.
  • Nombre de usuario o nombre de perfil.
  • Identificador de cuenta.
  • Información necesaria para autenticar al usuario.

Cuando el usuario inicia sesión con Google, el proceso de autenticación puede implicar el tratamiento de información por los servicios de Google, conforme a sus propias políticas.

3. Mensajes privados

PRIVATE CHAT permite intercambiar mensajes entre usuarios.

Para prestar este servicio, la aplicación puede procesar el contenido de los mensajes, los identificadores de los participantes, las fechas de envío y la información necesaria para entregar las comunicaciones.

La aplicación incorpora funcionalidades de eliminación automática de mensajes.

La eliminación de mensajes dentro de la aplicación no garantiza por sí sola la eliminación inmediata de todas las copias, registros técnicos o copias que puedan existir en otros dispositivos.

4. Fotografías y archivos multimedia

PRIVATE CHAT permite compartir fotografías y otros contenidos multimedia.

La aplicación puede acceder a los archivos seleccionados por el usuario para enviarlos a sus destinatarios.

PRIVATE CHAT incorpora una funcionalidad de marca de agua en fotografías.

Esta función está destinada a identificar el contenido compartido, pero no impide completamente su reproducción o distribución mediante otros dispositivos.

5. Llamadas de voz y vídeo

PRIVATE CHAT ofrece funciones de comunicación mediante llamadas.

Para realizar estas comunicaciones, la aplicación puede solicitar acceso al micrófono y, cuando corresponda, a la cámara del dispositivo.

Estos permisos se utilizan para permitir las funciones de comunicación solicitadas por el usuario.

El usuario puede gestionar los permisos desde la configuración de Android.

6. Protección mediante PIN

PRIVATE CHAT incorpora un sistema de acceso mediante PIN destinado a restringir el acceso no autorizado a la aplicación.

El PIN es una medida adicional de protección del acceso a la aplicación.

Su utilización no constituye por sí sola una garantía de cifrado de extremo a extremo.

7. Protección frente a capturas de pantalla

PRIVATE CHAT incorpora medidas destinadas a restringir las capturas de pantalla en determinadas interfaces.

Estas medidas pueden depender del sistema operativo y de las características del dispositivo.

Ninguna restricción de capturas garantiza que otro dispositivo externo no pueda fotografiar o grabar la pantalla.

8. Finalidad del tratamiento de datos

La información necesaria para el funcionamiento de PRIVATE CHAT se utiliza para:

  • Autenticar a los usuarios.
  • Administrar las cuentas.
  • Facilitar el envío y recepción de mensajes.
  • Permitir llamadas y comunicaciones.
  • Gestionar el contenido multimedia compartido.
  • Aplicar las funciones de privacidad.
  • Mantener el funcionamiento y la seguridad del servicio.

9. Servicios de terceros

PRIVATE CHAT utiliza el inicio de sesión con Google como método de autenticación.

Los servicios de terceros integrados en la aplicación pueden tratar información necesaria para prestar sus funciones.

El tratamiento realizado por Google se encuentra sujeto a sus correspondientes condiciones y políticas de privacidad.

Puedes consultar la política de Google en:

https://policies.google.com/privacy

10. Conservación de la información

Los datos de cuenta y las comunicaciones se conservarán durante el tiempo necesario para prestar los servicios correspondientes, de acuerdo con la configuración de la aplicación y las obligaciones legales aplicables.

PRIVATE CHAT dispone de funcionalidades relacionadas con la eliminación automática de mensajes.

Los periodos concretos de conservación, así como el alcance de las eliminaciones, dependen de la implementación técnica del servicio y de sus sistemas de almacenamiento.

12. Derechos de los usuarios

Los usuarios pueden solicitar, cuando resulte aplicable:

  • Acceso a sus datos personales.
  • Rectificación de información incorrecta.
  • Eliminación de sus datos.
  • Limitación del tratamiento.
  • Oposición al tratamiento.
  • Portabilidad de los datos.

Para ejercer estos derechos, pueden contactar con MaxStudio.

13. Seguridad

PRIVATE CHAT incorpora funciones orientadas a mejorar la privacidad de las comunicaciones.

Entre ellas se encuentran el acceso mediante PIN, la eliminación automática de mensajes y las restricciones de capturas de pantalla.

Ningún sistema informático puede garantizar una seguridad absoluta.

14. Privacidad de menores

El uso de PRIVATE CHAT por menores debe respetar la legislación aplicable y los requisitos de edad establecidos para la aplicación.

15. Cambios en esta política

MaxStudio podrá actualizar esta Política de Privacidad para reflejar cambios en la aplicación, sus funcionalidades o las obligaciones legales.

Las actualizaciones se publicarán en esta misma página.
